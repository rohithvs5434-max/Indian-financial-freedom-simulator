## 📖 About the Project

The **Indian Financial Freedom Simulator** is an interactive web application built with Python and Streamlit that helps users explore the long-term sustainability of a retirement plan under uncertain investment returns and inflation.

The application allows users to enter information about their:

- Current age
- Planned retirement age
- Life expectancy
- Current investments
- Annual savings
- Retirement expenses
- Equity allocation
- EPF
- PPF
- NPS
- Inflation assumptions
- Simulation settings

Instead of relying on one fixed investment return, the simulator uses **Monte Carlo simulation** to generate multiple possible financial scenarios.

Each simulated scenario can experience different investment returns and inflation conditions. The application then analyzes these scenarios and presents the results through financial metrics and interactive visualizations.

The central question behind the project is:

> **How resilient is a retirement plan when the future does not follow one fixed financial assumption?**

The purpose is not to predict exactly how much money a person will have in the future. Instead, the simulator provides a way to explore uncertainty, compare scenarios, and understand how different assumptions can affect retirement sustainability.
